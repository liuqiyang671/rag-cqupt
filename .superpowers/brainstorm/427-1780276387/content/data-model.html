数据模型设计

扩展 QARecord 模型以支持删除和归档功能

现有 QARecord 模型

当前数据库表结构
字段 类型 说明
id Integer 主键
question Text 用户问题
answer Text AI 回答
retrieved_context JSON 检索到的知识
model_provider String(50) 使用的模型
created_at DateTime 创建时间

新增字段

扩展后的表结构
新增字段 类型 默认值 说明
status String(20) 'active' 状态：active/archived/deleted
updated_at DateTime created_at 最后更新时间

设计说明：使用 status 字段而非多个布尔字段，更清晰地表达状态机。
状态流转：active → archived → deleted（硬删除）
