API 接口设计

新增和修改的 API 端点

现有 API

当前已有的 API
方法 路径 说明
POST /qa/ask 同步问答
POST /qa/ask/stream 流式问答
GET /qa/records 获取历史记录（分页）

新增 API

需要新增的 API 端点
方法 路径 参数 说明
GET /qa/records ?status=active&skip=0&limit=20 修改：支持按状态筛选
PUT /qa/records/{id}/archive - 归档记录
PUT /qa/records/{id}/restore - 恢复归档记录
DELETE /qa/records/{id} - 硬删除记录（确认后）
GET /qa/records/{id} - 获取单条记录详情
